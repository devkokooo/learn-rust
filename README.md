# Learn Rust 🦀

Learning Rust from the Rust book - https://doc.rust-lang.org/stable/book

This is done alongside rustlings - https://rustlings.rust-lang.org/

## Navigation

To start rustlings:
```sh
$ cd rustlings
$ rustlings
```
